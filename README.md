# OOP Mastery - Beginner to Expert

## Focus: 4 Core OOP Concepts

This curriculum teaches **Encapsulation**, **Inheritance**, **Polymorphism**, and **Abstraction** through clear briefings and hands-on exercises.

### Module Structure
Each module has:
1. **BRIEFING.md** — What is this concept? Why do we need it? (READ THIS FIRST)
2. **concept_examples.dart** — Working code you can run
3. **exercise1.dart** & **exercise2.dart** — Problems for you to solve

### Run Files
```bash
dart run path/to/file.dart
```

---

## Modules

### Module 0: Prerequisites (Optional)
- Refresh Dart fundamentals: variables, loops, functions, lists
- Skip if you're confident in these topics

### Module 0.5: Introduction to Classes & Constructors (REQUIRED)
- What is a class? What is a constructor?
- How to create objects with constructors
- Essential knowledge before any OOP concept

### Module 1: Encapsulation
- Hide internal state, control access with getters/setters

### Module 2: Inheritance  
- Reuse code by extending classes, build hierarchies

### Module 3: Polymorphism
- Same method call, different behavior by type

### Module 4: Abstraction
- Define contracts, force implementation of critical methods

Start with **Module 1 → BRIEFING.md** and work sequentially.
